## Source of truth

- If documents conflict, report the conflict instead of silently choosing.

- Preserve existing repository structure and work.

## Workflow
1. Audit the repository and identify what already exists.
2. Map the task to the relevant source-of-truth documents.
3. Split work into small, testable tasks.
4. Implement one coherent task at a time.
5. Test in Roblox Studio or with available checks.
6. Update relevant documentation and task status.
7. Report changed files, tests actually run, remaining risks, and the next task.

This is a planning index, not permission to redesign the game. Owner-approved decisions and the existing FLORA documents define the game.
