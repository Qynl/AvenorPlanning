## Status convention
- **Confirmed:** directly chosen by the user.
- **Proposal:** a recommended direction that still needs approval or testing.
- **TBD:** intentionally unresolved.

This is a design repository. A planned feature is not an implemented feature. Keep decisions explicit and update the relevant document when a direction changes.
