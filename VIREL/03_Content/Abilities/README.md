## Relationship rules
- Parent plant page owns set identity, rarity, theme and unlock sequence.
- Individual ability page owns detailed mechanics, limitations, balance and presentation.
- Ability folders group files by parent plant.
- Every ability links back to its parent plant.
- Every plant links to all abilities in its set.
- No orphan abilities.

Use [Ability Template](../../Templates/Ability_Template.md) for new abilities. See [shared ability rules](../../04_Systems/Abilities/README.md).
