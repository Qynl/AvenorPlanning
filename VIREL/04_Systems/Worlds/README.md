# World Rotation and Ecology

## World structure
VIREL contains multiple enormous worlds, each with unique biomes, hidden sub-regions and native species. The initial proposal contains ten worlds.

## Rotation
Worlds may enter and leave the active roster over time. Exact cadence and active count are TBD.

## Fairness rules
- Research and discoveries persist permanently.
- Core progression cannot depend on a narrow availability window.
- Rotated worlds need a fair return, archive or recovery path for essential content.
- Rotation should create anticipation, not FOMO pressure.

## Ecology
Potential variables include time of day, weather, temperature, humidity, light, water level, wind, altitude, events and nearby species. Use a small set of meaningful variables rather than an expensive simulation that players cannot understand.
