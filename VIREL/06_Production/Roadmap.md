# FLORA — Production Roadmap

## Phase 0 — Design foundations
- [x] Establish game identity and core pillars.
- [x] Establish rarity ladder and initial content direction.
- [x] Create structured world, plant and ability documentation.
- [ ] Resolve encounter structure and PvE/PvP direction.
- [ ] Resolve ability loadout and research unlock rules.

## Phase 1 — Core prototype
- [ ] Establish a repeatable Roblox Studio project structure.
- [ ] Greybox one complete biome using the world-building pipeline.
- [ ] Validate streaming and low-end performance before final art.
- [ ] Build one reusable foliage and rock asset kit.
- [ ] Third-person movement and camera.
- [ ] One small exploration region.
- [ ] Scanner interaction and discovery record.
- [ ] One complete plant research path.
- [ ] One full plant ability set.
- [ ] Basic encounter target and combat feedback.

## Phase 2 — Vertical slice
- [ ] One polished biome with hidden sub-region.
- [ ] Several plants across different rarities.
- [ ] Several complete ability sets.
- [ ] Repeatable encounter loop.
- [ ] Multiplayer replication and performance tests.
- [ ] Cinematic discovery and unlock presentation.

## Phase 3 — Content foundations
- [ ] Convert the 50-plant catalogue into a prioritised production schedule.
- [ ] Build data-driven plant and ability definitions.
- [ ] Add automated checks for missing parent links and ability references.
- [ ] Reusable world/biome pipeline.
- [ ] Reusable plant and ability data pipeline.
- [ ] Research archive and progression persistence.
- [ ] Streaming and memory budgets.

## Phase 4 — Expansion
- [ ] Establish a repeatable world map assembly pipeline.
- [ ] Complete mobile and low-end performance acceptance tests.
- [ ] Build a reusable biome kit and plant habitat kit.
- [ ] Additional biomes and worlds.
- [ ] More plant families and ability sets.
- [ ] Events and world rotation.
- [ ] Mastery, long-term progression and social systems.

Milestones are planning targets, not a commitment to a launch date or content count.
