## Plant specification rules
- One plant folder per species.
- Plant file is the source of truth for species identity and set membership.
- Each ability links back to its parent plant and its set.
- Ability mechanics are specified in the [Ability Directory](../../03_Content/Abilities/README.md).
- The home world links back to the plant file.
- Use [Plant Template](../../Templates/Plant_Template.md) for new species.
