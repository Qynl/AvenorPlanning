# AVENOR — World Rotation & Dynamic Events

> Events enrich the exploration sandbox. They must not turn the game into compulsory missions or constant UI alerts.

## World rotation
One active Open World region is available across multiple Roblox server instances. Four days is the current proposal, not a locked rule. Rotation is a world event/calendar change, not a separate mode. All servers use the same active world identity and schedule. A region may return later with seasonal dressing or new activities.

## Persistence
Permanent: account level/XP, owned weapons, mastery, cosmetics, loadouts, currency, achievements, journal entries and competitive rank.
Cycle-local: temporary NPC placements, incidents, local activity state, event access and cycle leaderboards.
Never remove permanent ownership or punish players for missing a cycle. Permanent discoveries need a fair future return path.

## Ambient and dynamic incidents
Examples: travelling expedition arrives at a landmark; trader reaches a settlement; local power outage changes access/ambience; research team opens a temporary site; weather shifts; two NPC groups meet; security incident draws local attention; community discovery becomes a rumour. Players notice through environment, NPC behaviour or local cues. Participation is optional.

## Seasonal transformations
Halloween/autumn, winter, summer and original AVENOR incidents may transform the active region with dressing, NPCs, ambience and meaningful exploration/social activities. Preserve navigation and combat readability.

## Event requirements
Each major event needs a reason to exist, diegetic discovery cues, optional participation, solo-accessible content where practical, fair rewards, permanent/temporary status clarity, performance budget and return/archive plan.

## Calendar and transition
The home screen may show active/next world, time remaining, seasonal event and recent community discoveries. Announce next region, stop starting cycle activities that cannot finish, save relevant data, route new joins at activation, transition existing servers gracefully and preserve permanent records. Use one authoritative schedule across servers.

## Open decisions
Exact cadence, UTC time, world order, event frequency, rewards, seasonal map coverage and shared community milestones remain TBD.
